# 猪圈日报

猪圈日报把当天群内 RollPig 活动整理成一张可分享的视觉战报，并可在每天固定时间自动发送到原群聊。

## 日报内容

新版海报仍然只使用现有真实统计字段，但展示方式从「数字结算页」改成更适合聊天阅读的图表化战报：

- **今日主旋律**：根据当天已有抽猪、烧烤、被吃、逃脱、反噬、补货数据挑选一条解释性文案，不新增持久化指标，也不伪造评分；
- **摘要指标**：今日活跃猪友、抽猪人数、成功烧烤、被吃人数、逃脱次数、反噬次数，并以迷你比例条辅助扫读；
- **今日搞事分布**：对抽猪、烧烤、被吃、逃脱和反噬的原始 count 做同图横向比较；
- **今日热猪榜**：继续沿用 `popular_pigs` 的真实并列热门结果；如果所有猪只各出现一次，则明确显示「没有热门款」，不会凭空选第一名；
- **猪圈名人堂**：继续展示「烧烤狂人」「最惨食材」「逃脱大师」「反噬之王」，并保留真实并列关系；
- **补货摘要**：展示当天补货成功次数与添柴支持人次；
- **今日祭品**：仅在既有自动祭品流程真实触发时出现。

称号出现并列时会保留真实并列关系。海报主卡展示一名代表并注明并列人数，不会随机伪造唯一第一名。

称号获得者会优先使用平台事件提供的昵称和头像。头像获取失败、超时或平台不提供头像时自动退回昵称首字占位，不影响整张日报生成与发送。

手动执行 `/猪圈日报` 只生成当前群当天的海报，不会触发「今日祭品」。

## 图片尺寸与聊天清晰度

日报画布固定为 **1200px 宽**：

- 普通日报：`1200 × 1280`；
- 含「今日祭品」：`1200 × 1390`；
- renderer 硬上限：`1400px` 高。

旧版固定高度是 1680px，含祭品时可到 1965px。新版通过压缩 Hero、图表化摘要与固定高度名人堂，把信息保留下来的同时降低 QQ 等聊天平台缩放／二次压缩造成的文字模糊风险。

PNG 使用低 CPU 压缩级别输出；这不会改变像素质量，主要减少渲染时不必要的 CPU 消耗。

## 自动发送

插件会在群友使用 RollPig 时保存 AstrBot 的 `unified_msg_origin`，从而在当天事件对象已经结束后仍能主动把日报投递回同一个群。

自动发送先锁定 `report_date`，再计算随机延迟；延迟会被限制在该自然日结束前，因此不会跨到次日发送。统计数据和可选祭品始终只属于锁定的报告日期。

每个群、每天的发送任务都会保存状态和随机延迟。插件重启后会在允许的补发窗口内继续未完成任务；已经成功发送的任务不会正常重复执行。

## 今日祭品

`daily_report_random_eat_enabled` **默认关闭**。

开启后，仅自动日报发送流程会从当天在该群实际参与 RollPig、当前仍有可被吃小猪的用户中随机选择一人，将锁定日期的状态改为「吃掉了」。它复用现有被吃持久化与次日抽猪惩罚语义，并把祭品展示在日报底部。

手动 `/猪圈日报` 永远不会触发祭品，避免用户反复查询造成状态变化。

## 配置

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `enable_daily_report` | `true` | 日报总开关 |
| `daily_report_auto_send` | `true` | 是否每天自动发回活跃群 |
| `daily_report_send_time` | `23:50` | 使用 `timezone` 的 `HH:MM` 时间 |
| `daily_report_random_delay_minutes` | `10` | 在设定时间后随机延迟 0–N 分钟，范围 0–60 |
| `daily_report_skip_empty_groups` | `true` | 无当天抽猪记录时跳过自动日报 |
| `daily_report_random_eat_enabled` | `false` | 自动日报随机祭品，默认关闭 |
| `daily_report_avatar_enabled` | `true` | 尝试显示平台头像 |
| `daily_report_avatar_cache_hours` | `24` | 平台头像本地缓存时长，范围 1–168 小时 |

日报沿用插件现有 `timezone` 和 `image_theme` 配置，因此每日边界、自动发送时间与日夜配色保持一致。

## 数据与隐私

日报辅助状态只保存生成日统计所需的群会话路由、用户展示昵称、头像地址/缓存、玩法事件与任务状态；核心抽猪和「吃掉了」状态继续由现有 SQLite/JSON 存储权威管理。辅助事件与任务默认只保留近期数据，头像也按配置缓存并可自然更新。

## 群組自動推送（預設關閉）

自動推送採 **per-group opt-in**。即使插件全局 `enable_daily_report` / `daily_report_auto_send` 開啟，新群與既有未標記群也一律視為未開啟，不會因曾經記錄到 `unified_msg_origin` 就自動收到日報。

- `/豬圈日報`：手動查看本群今日報告，不改推送設定；
- `/豬圈日報 開啟`：僅 AstrBot 管理員可開啟本群自動推送；
- `/豬圈日報 關閉`：僅 AstrBot 管理員可關閉本群自動推送；
- `/豬圈日報 狀態`：查看本群與全局 master switch 狀態。

這裡的「AstrBot 管理員」以 AstrBot 自身的管理員判定／`admins_id` 為準，不採用 QQ、Telegram 等平台原生群主或群管理員角色。

群組今天才開啟時不會補發開啟日前的舊日報；隨機延遲也會被限制在報告自然日結束前。重啟 catch-up 僅對當時已 opt-in 的群生效。
