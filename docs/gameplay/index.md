# 🎮 玩家玩法總覽

你不需要一次看完所有規則。下面只告訴你「能玩什麼」；概率、限制和例外放在對應專頁。

<div class="pig-card-grid">
<div class="pig-card" markdown>
<span class="pig-card__icon">🐷</span>

### 每日小豬
每天抽自己的今日小豬，也能查看昨天、明日預測和本週摘要。

<span class="pig-command">/今日小豬</span>
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">📚</span>

### 永久豬籍與保底
抽到過的小豬會留在收藏；重複抽取會推進 EX，也可能提高下一次遇到新豬的機會。

[看收藏與保底 →](collection-pity.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">⭐</span>

### EX 成長
同一隻小豬從第二次抽到開始提升 EX。高 EX 可以有不同圖片、描述和文案。

[看 EX 成長 →](ex-growth.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">🔥</span>

### 群聊後廚
可以烤群友、預約還沒抽豬的人，也可能遇到逃脫或反噬。

<span class="pig-command">/烤群友 @某人</span>

[看群烤結果 →](roast-outcomes.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">⚡</span>

### Roast Charge、補貨與添柴
普通群烤會消耗 Charge。沒能量時可以發起群體補貨；`/添柴` 也能按情況加入補貨或預約。

[看 Charge 與添柴 →](roast-charge.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">📰</span>

### 豬圈日報
把今天的抽豬、燒烤、逃脫、反噬和被吃事件整理成一張日報。

<span class="pig-command">/豬圈日報</span>

[看日報規則 →](daily-report.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">🔎</span>

### 圖鑑探索
可以隨機看豬或按關鍵詞搜尋，不會改變今天已抽到的結果。

<span class="pig-command">/隨機小豬</span>
<span class="pig-command">/找豬 關鍵詞</span>
</div>
</div>

需要完整別名、權限和上下文限制時，再看 **[指令百科](../COMMANDS.md)**。
