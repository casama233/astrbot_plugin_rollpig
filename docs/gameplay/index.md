# 🎮 玩家玩法總覽

不用一口气硬啃整本说明书，这里先带你速览“群里能玩什么”；具体的触发概率、次数限制与特殊例外，都收在各自的专题页面里。

<div class="pig-card-grid">
<div class="pig-card" markdown>
<span class="pig-card__icon">🐷</span>

### 每日小豬
每天上线抽一只专属的今日小猪，还能顺道翻翻昨天的回顾、偷窥明日运势预测，以及查看本周抽猪小结。

<span class="pig-command">/今日小豬</span>
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">📚</span>

### 永久豬籍與保底
抽到过的小猪会自动登记进永久图鉴；重复入手不仅能推进 EX 成长等级，还会暗中提高下次邂逅未解锁新猪的机会。

[看收藏與保底 →](collection-pity.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">⭐</span>

### EX 成長
同一只小猪从第二次抽到开始解锁 EX 升级。等级越高，就能展示越丰富的专属立绘、简介与故事文案。

[看 EX 成長 →](ex-growth.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">🔥</span>

### 群聊後廚
可以直接把群友架上烤架，或提前预约还没抽猪的人，不过随时也可能翻车，遇到小猪挣脱逃跑甚至当场反噬。

<span class="pig-command">/烤群友 @某人</span>

[看群烤結果 →](roast-outcomes.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">⚡</span>

### Roast Charge、補貨與添柴
发动普通群烤会消耗烤箱能量（Charge）。火力耗尽时可以号召全群一起补货；`/添柴` 也能视当前战况加入添柴补货或参与预约。

[看 Charge 與添柴 →](roast-charge.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">📰</span>

### 豬圈日報
把群里一整天的抽猪收获、烧烤盛况、惊险逃脱、惨遭反噬与被吃现场，通通汇总成一张热闹的每日战报。

<span class="pig-command">/豬圈日報</span>

[看日報規則 →](daily-report.md)
</div>

<div class="pig-card" markdown>
<span class="pig-card__icon">🔎</span>

### 圖鑑探索
随时可以在猪圈里随机闲逛，或是输入关键词精准搜猪，纯逛图鉴绝对不会影响你今天已经抽到的结果。

<span class="pig-command">/隨機小豬</span>
<span class="pig-command">/找豬 关键词</span>
</div>
</div>

## 不確定該敲哪條指令？ {.pig-section-title}

先在群里发送 **`/豬豬幫助`**，系统会自动根据当前已开启的功能模块，为你列出眼下可用的全部玩法。

如果想进一步查阅完整指令别名、管理权限与触发场景限制，再去翻阅 **[指令百科](../COMMANDS.md)** 即可。
