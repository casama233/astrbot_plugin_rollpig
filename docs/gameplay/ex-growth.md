## 現在每隻豬都有專屬的「手寫」EX 文案嗎？

**沒錯。目前正式官方圖鑑收錄的 201 隻豬，全數具備人工逐隻撰寫的 EX1～EX5。**

不再是過去「10 隻精品＋ 191 隻套版湊數」的配置了，現在是：

```text
99 隻 bundled 主目錄
+ 102 隻 compatibility 恢復舊豬
= 201 隻正式官方豬
= 201 隻全部精品手寫五級 EX
```

每一隻都擁有：

- 5 句各具特色的簡短評語；
- 5 段彼此獨立的完整故事；
- 緊扣角色原始人設與笑點延伸的連貫成長曲線。

換句話說，當你把同一隻豬一路養到 EX1、EX2、EX3、EX4、EX5，看到的不再是「變熟了」「老主顧」「完全體」這類千篇一律的套話，而是每個角色專屬的劇情推進。

有的豬會從只會闖禍慢慢學會拿捏分寸，有的從處處受制逐步掌握主導權，也有的把最初的純粹搞笑梗，一路昇華成更具靈魂的招牌形象。

## 怎麼確保日後不會又退回套版生成？

目前 CI 流程不只檢查「終態是否有 EX 資料」，更會直接核對**明確的創作清單（authoring 集合）**：

```text
handcrafted EX IDs == official pig IDs == 201
```

且清單中的每個 ID 都必須符合：

- 恰好有 EX1～EX5；
- 五階 `description` 皆不為空且互不重複；
- 五階 `analysis` 皆不為空且互不重複。

因此往後只要新增官方正式豬隻，若只拿保底生成器敷衍而未補齊手寫精品文案，Resource Source 檢查關卡就會直接亮紅燈，無法當作完成品發布。

## 那個自動生成五級內容的生成器還在運作嗎？

還在，不過現在的定位已經退居為**系統安全備援**。

它目前僅負責處理：

- 本地自行建立或非官方來源的小豬；
- 測試 fixture；
- 還沒正式收錄進精選圖鑑庫（curated catalog）的過渡性內容；
- 資料異常回退時，確保整個 EX 成長展示不會直接開天窗。

標準的官方 201 隻小豬絕不該依賴它自動產出。正式發佈的內容審核門檻會強制要求 201/201 必須由人工親自撰寫。

## EX 系統還支援手動客製專屬圖片或局部內容嗎？

可以。資源作者仍可針對 **EX Lv.1–5** 覆寫：

- 🖼️ 圖片
- 📝 短描述
- 💬 完整專屬文案

第三方／本地作者不需要像官方內容庫一樣強制寫滿五級。稀疏差分仍按欄位向高級繼承：哪一級真的值得換圖或特製內容，就只寫那一級。

要求官方 201 隻小豬「全五級皆為人工撰寫」是針對官方內容的品質規範，並不會破壞 EX 協議原本保留的彈性擴充機制。

## EX 系統絕對不會在背後偷改哪些東西？

EX 單純是**外觀展示與收藏養成層**，不會偷偷把同一隻小豬竄改為另一個規則實體。

它完全不會更動以下設定：

- 小豬 ID
- 小豬的原本名稱
- 各池子的抽取機率
- 系統的保底計算規則
- 能不能進烤箱、能不能被吃掉等玩法判定資格
- 你最核心的收藏權威紀錄

> 因此 EX Lv.5 並不會因為「長大變熟了」就擅自把 10% 的反噬效果改寫成 100%——雖然那樣聽起來確實挺有戲劇張力的。

## 玩家會在哪些地方看到 EX 成長變化？

只要是玩家**已經實際入手**的小豬，對應的 EX 差分外觀與文案就會在今日抽豬、歷史紀錄、週視圖、永久圖鑑以及相關料理卡片等介面中呈現。

但 `<span class="pig-command">/明日小豬</span>` 僅屬於預知功能，並不代表你已經真正擁有明天那隻豬，因此不會提前套用你個人的 EX 收藏差分。

## EX 成長與抽卡保底之間是什麼關係？

這兩者是完全獨立運作的機制：

- **EX 成長**：記錄你「同一隻豬已經重複抽到第幾次」，把重複入手轉化為看得見的養成進度。
- **新豬保底 / 跨日疲勞**：當你連續重複抽到舊豬太多次時，逐步提高下一次重抽遇見未解鎖新豬的機率。

簡單來說，一個負責讓重複抽卡**累積成就與成長感**，另一個則負責避免你**天天都只能盯著同一張豬臉**。

## 給群組管理員：可以不用手動修改 JSON 設定檔嗎？

沒問題，插件內建了獨立的 **EX 成長管理** 後台頁面，你可以直接在介面上：

- 搜尋並鎖定目標小豬；
- 逐級編輯 EX Lv.1–5 的簡介與完整故事文案；
- 自由上傳或移除各等級專屬的差分立繪；
- 欄位留空時自動依照本地稀疏繼承規則沿用上級設定；
- 即時預覽前台「實際生效展示」的最終效果。

如果管理員只修改了基礎小豬資料而未建立本地 EX 設定，公共 EX 庫不會擅自覆蓋你的本地更動；唯有明確建立本地 EX 條目後，才會由本地 EX 取得最高顯示優先權。

## 給創作者：我能把 EX 投稿公共源嗎？

支援的。透過 EX-aware 投稿流程，系統會把基礎小豬資料與圖片、本地 EX 差分設定，以及差分所引用的全部圖片打包為**同一次人工審核案件**送出。

審核人員可以逐級檢視差分文案與立繪；審核通過後，基礎資料與 EX 內容會在同一個候選資源包內進行完整校驗並原子化同步發布。通用生成器雖然仍可為尚未補齊 EX 的非官方候選提供安全備援，但若一隻新豬想正式晉升為官方精選圖鑑庫（curated catalog）成員，就必須填滿五級人工精品文案才能跨過官方發佈門檻。

舊版不含 EX 設定的投稿格式依然完全相容；底層正式資源規範也維持為 Resource Protocol v1。
