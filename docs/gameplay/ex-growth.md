# ⭐ EX 成長：同一隻豬，養熟了會變樣

<div class="pig-highlight" markdown>

第一次抽到：**你好，新豬。**  
第二次抽到：**你怎麼又來了。**  
第五次、第六次還在來：**行吧，這已經是你家豬了。**

EX 系統就是把「重複抽取」從純粹的重複，變成一條可見的收藏成長線。

</div>

## EX Lv. 怎麼算？

規則很直白：

```text
EX Lv. = max(0, 這隻豬的累計抽取次數 - 1)
```

也就是：

| 你抽到這隻豬第幾次 | 顯示 |
| --- | --- |
| 第 1 次 | EX Lv.0（首次解鎖） |
| 第 2 次 | EX Lv.1 |
| 第 3 次 | EX Lv.2 |
| 第 4 次 | EX Lv.3 |
| 第 5 次 | EX Lv.4 |
| 第 6 次 | EX Lv.5 |
| 第 7 次以後 | EX 還會繼續升，但視覺差分目前最高使用 Lv.5 的最後有效內容 |

## EX 會改變什麼？

資源作者可以針對 **EX Lv.1–5** 選擇性修改：

- 🖼️ 圖片
- 📝 短描述
- 💬 完整文案

而且不需要每一級都做。

比如某隻「睡覺豬」只有 EX2 換圖片、EX4 換文案、EX5 再換一次圖片，那麼中間等級會自動沿用最近一個有效差分。

!!! success "這叫稀疏差分"
    不需要為 EX1、EX2、EX3、EX4、EX5 各複製一整份資料。**哪裡真的變了，就只寫哪裡。**

## EX 不會偷偷改什麼？

這點很重要。

EX 是 **展示與收藏成長層**，不是偷偷把同一隻豬換成另一隻規則實體。

它不會修改：

- 小豬 ID
- 小豬名稱
- 抽取概率
- 保底規則
- 能不能烤、能不能吃之類的玩法資格
- 你的收藏權威資料

> 所以 EX Lv.5 不會突然因為「長大了」就把 10% 反噬改成 100%。雖然那聽起來很有節目效果。

## 哪些地方會看到 EX？

對玩家**已經真正擁有**的小豬，EX 差分可以出現在今日、歷史、週視圖、永久圖鑑以及相關料理卡等展示中。

但：

<span class="pig-command">/明日小豬</span>

只是預測，不代表你已經擁有明天那隻，所以不會提前套用你的 EX 收藏差分。

## EX 和保底是什麼關係？

它們不是同一套東西：

- **EX**：告訴你「同一隻已經抽到第幾次」。
- **新豬保底 / 跨日疲勞**：在重複太多時，增加下一次重抽到未解鎖小豬的機會。

一個負責讓重複抽取**有成長感**，另一個負責避免你**永遠只見同一張豬臉**。
