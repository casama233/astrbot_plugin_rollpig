# 公共灾备猪源审核边界

## 当前行为

v3.12.3 起，官方链依次尝试主源、固定 Vercel 镜像、固定 GitHub 镜像。镜像沿用来源服务已经完成的权利审核及正式 `2026.09.05.1` 发布，包含 164 只猪、820 级 EX；图片、文本、NOTICE、PROVENANCE、LICENSES 和 EX-AUTHORING 均按原发布逐字节保留。

仅有镜像 URL 或相同版本号不能通过检查。插件从固定 GitHub API 独立读取当前批准表，核对 manifest SHA-256、完整协议、来源／授权资料、逐文件大小与 SHA-256；下载后再次读取批准表，再将已验证的暂存内容交给原有原子同步事务。镜像不能通过第二次请求替换已验证 manifest。

已知比本地旧的资源版本不能降级覆盖；即使版本相同也完整核验并修复缓存。镜像配置仅接受默认官方地址；空 Vercel 地址或关闭 GitHub 开关可停用对应备用。私人 manifest 仍保持单一来源，不会偷偷进入公共链。

## 故障与撤回

主源优先。镜像批准表不可读、未批准、已撤回、内容缺失或损坏时，不启用该镜像，继续尝试下一个允许来源；全部失败保留最近一次已验证本地资源，缺少缓存时使用内置资源。

当当前批准表明确撤回或移除某个镜像快照，插件将该 mirror-origin 缓存移出 active 目录，保留恢复材料但停止用于图鉴，回到内置／本地层。撤回在下一次成功读取批准表时生效；断网无法证明是否发生撤回。镜像切换需独立访问 GitHub 批准 API，API 限流／故障会阻止新的镜像安装。

维护者通过镜像仓库的撤回脚本同步修改批准表、删除 public/v1 并部署。Vercel 返回公告页，GitHub main 移除快照；旧 Git 历史和旧部署地址不属于受支持的自动 fallback 链。需要平台级追溯清理时应另行删除相关历史部署。

## 审核范围

该镜像是明示版本的已批准快照，不能自动批准未来主源版本。新增版本沿用来源服务的新审核与正式发布记录，更新精确批准表后才能镜像。未审核投稿、后续受限替换图、未知来源、私人审核包、令牌、数据库及字体现阶段均不新增发布。

保留 `PUBLIC_MIRROR_FAIL_CLOSED` 紧急总开关；其关闭强制封锁只与本次完整校验器一起发布。现有玩家玩法、数据 schema、Felis 直读限制及历史素材隔离不变。

## v3.12.4 同版本與來源記錄

檢查過某個遠端不代表本地檔案已來自該遠端。同版本且沒有替換資源時，保留原 source_name、source_url 和鏡像批准雜湊；只有完整交易成功後才改寫來源。鏡像轉主源、切換私人源或来源未知時強制完整同步。

成功完整同步會保存 manifest_sha256。同一來源的同版本快取只有 manifest 雜湊也一致，才可略過重複下載；舊版曾遺失来源／批准資訊的快取缺少此記錄，會在下一次同步重新驗證，不能只憑版本號報成功。這不等於每次都重新校驗所有本地圖片；疑似損壞時仍可強制同步。

撤回檢查同時辨識批准雜湊、鏡像來源名稱與固定鏡像 URL，避免只改來源標籤就跳過撤回。成功完整取得主源資源後才移除旧鏡像批准記錄。批准表無法取得時仍不能推斷撤回已發生；沒有變更既有授權範圍或發布方式。
