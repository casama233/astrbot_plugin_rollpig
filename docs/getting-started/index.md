# ⚡ 30 秒開始養豬

<div class="pig-player-entry" markdown>

**這頁是給群友的，不是給插件管理員的。**

只要你所在的群裡已經有《今日小豬 · 增強版》，就不用先安裝、不用重啟 AstrBot、也不用看配置文件。直接從第一條指令開始。

</div>

<div class="pig-steps pig-steps--player">
<div class="pig-step" markdown>
<span class="pig-step__n">1</span>
<div>
<span class="pig-step__eyebrow">FIRST CONTACT</span>

### 抽你今天的第一隻豬
<span class="pig-command">/今日小豬</span>

同一位使用者同一天第一次抽取後，結果就固定。**一直重發不會洗豬。**
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">2</span>
<div>
<span class="pig-step__eyebrow">KEEP IT</span>

### 看看它有沒有進永久豬圈
<span class="pig-command">/我的豬圈</span>

圖鑑會記住你解鎖過哪些小豬、抽過幾次，以及目前的 EX Lv.。今天抽完，明天它也不會憑空消失。
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">3</span>
<div>
<span class="pig-step__eyebrow">CHAOS MODE</span>

### 然後開始把群聊搞亂
<span class="pig-command">/烤群友 @某人</span>
<span class="pig-command">/烤箱補貨</span>
<span class="pig-command">/添煤</span>
<span class="pig-command">/豬圈日報</span>

到這一步，你已經不是單純來看一張隨機圖片了。你正在參與一個有收藏、能源、預約、協作和晚報的群聊後廚。
</div>
</div>
</div>

!!! tip "不知道群裡到底開了哪些玩法？"
    輸入 **`/豬豬幫助`**。幫助卡會依目前真正啟用的功能動態生成；管理員關掉的玩法不會硬塞給你。

## 第一隻豬之後能做什麼？ {.pig-section-title}

<div class="pig-card-grid">
<div class="pig-card" markdown>
<span class="pig-card__icon">📚</span>

### 收集
每天來一次，慢慢把永久圖鑑填滿。重複抽取不是完全白給，它還會推進 EX 成長與保底狀態。

[去看 EX 成長 →](../gameplay/ex-growth.md)
</div>
<div class="pig-card" markdown>
<span class="pig-card__icon">🔥</span>

### 開火
群烤現在消耗 Roast Charge。人還沒抽？可以先預約。沒能量？叫群友一起補貨。

[去看 Roast Charge →](../gameplay/roast-charge.md)
</div>
<div class="pig-card" markdown>
<span class="pig-card__icon">📰</span>

### 看今天誰最慘
晚一點用 `/豬圈日報` 看看誰是燒烤狂人、最慘食材、逃脫大師或反噬之王。

[翻開日報 →](../gameplay/daily-report.md)
</div>
<div class="pig-card" markdown>
<span class="pig-card__icon">🧭</span>

### 不知道下一條指令打什麼
不用背全部命令。先開 `/豬豬幫助`，或者到指令百科按玩法找你想做的事。

[打開指令百科 →](../COMMANDS.md)
</div>
</div>

## 常用指令先記這幾個 {.pig-section-title}

| 指令 | 你會得到什麼 |
| --- | --- |
| `/今日小豬` | 今天屬於你的那一隻 |
| `/我的豬圈` | 永久收藏與 EX Lv. |
| `/昨日小豬` | 昨天真的抽到什麼 |
| `/明日小豬` | 明天的固定預測，不提前解鎖 |
| `/本週小豬` | 七日週報 |
| `/烤群友 @某人` | 把群友送往後廚 |
| `/烤箱補貨` | 發起一次群體補貨 |
| `/添煤` | 參與目前補貨輪次 |
| `/豬圈日報` | 今天整個群發生了什麼 |

完整別名、上下文限制與更多玩法，請直接看 **[指令百科](../COMMANDS.md)**。
