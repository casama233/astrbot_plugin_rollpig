# ⚡ 30 秒光速開啟養豬生活

只要群里装好了《今日小猪》，普通玩家根本不用折腾任何设置，直接记住下面三条指令就能马上开养。

<div class="pig-steps pig-steps--player">
<div class="pig-step" markdown>
<span class="pig-step__n">1</span>
<div>

### 領取今日份的小豬
<span class="pig-command">/今日小豬</span>

每天第一次抽取就会锁定当天结果，之后不管怎么刷屏也不会重抽。
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">2</span>
<div>

### 翻閱你的專屬豬圈
<span class="pig-command">/我的豬圈</span>

随时查看已解锁的小猪图鉴、返场次数以及 EX 进阶等级。
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">3</span>
<div>

### 打聽群裡開放了哪些玩法
<span class="pig-command">/豬豬幫助</span>

帮助卡片只会展示群管实际开启的功能，省去死记硬背全套指令的麻烦。
</div>
</div>
</div>

## 想找樂子搞點事時，再記這幾條 {.pig-section-title}

| 想做什麼 | 指令 |
| --- | --- |
| 烤某位群友 | `/烤群友 @某人` |
| 發起群體補貨 | `/烤箱補貨` |
| 支持補貨或預約 | `/添柴` / `/添柴 @某人` |
| 看今天群裡發生了什麼 | `/豬圈日報` |

`/添柴` 会根据当前状态智能选择补货或预约；如果想精准指定某一张预约，请使用 `/添柴 @目標`。
