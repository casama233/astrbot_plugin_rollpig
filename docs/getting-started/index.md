# 🚀 5 分鐘開始養豬

!!! quote "豬圈入場須知"
    這頁的目標不是把你培養成豬源維護工程師。**五分鐘內抽到第一隻豬，就算勝利。**

<div class="pig-steps">
<div class="pig-step" markdown>
<span class="pig-step__n">1</span>
<div>

### 安裝《今日小豬 · 增強版》
推薦直接在 AstrBot 插件管理介面搜尋 **「今日小豬 · 增強版」** 或 `astrbot_plugin_rollpig_plus`。

手動安裝時，請使用獨立的 Plus 目錄，不要覆蓋舊 `astrbot_plugin_rollpig`。
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">2</span>
<div>

### 重啟 AstrBot，確認豬圈開門
插件正常載入後，先輸入：

<span class="pig-command">/豬豬幫助</span>

幫助卡會依你目前真正開啟的功能動態生成。管理員關掉的玩法，不會硬塞在裡面誘惑你。
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">3</span>
<div>

### 抽第一隻
<span class="pig-command">/今日小豬</span>

同一位使用者同一天第一次抽取後，結果就固定。**重複查不會洗豬。**
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">4</span>
<div>

### 看看它有沒有進永久豬圈
<span class="pig-command">/我的豬圈</span>

圖鑑會記住你解鎖過哪些小豬、抽過幾次，以及目前的 EX Lv.。
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">5</span>
<div>

### 然後開始把群聊搞亂
<span class="pig-command">/烤群友 @某人</span>
<span class="pig-command">/烤箱補貨</span>
<span class="pig-command">/添煤</span>
<span class="pig-command">/豬圈日報</span>

到這一步，你已經不只是養豬了。你正在參與一個有能源、預約、協作和晚報的群聊後廚系統。
</div>
</div>
</div>

## 第一隻豬之後能做什麼？

<div class="pig-card-grid">
<div class="pig-card" markdown>
<span class="pig-card__icon">📚</span>

### 收集
每天來一次，慢慢把永久圖鑑填滿。重複抽取不是完全白給，它還會推進 EX 成長與保底狀態。

[去看 EX 成長 →](../gameplay/ex-growth.md)
</div>
<div class="pig-card" markdown>
<span class="pig-card__icon">🔥</span>

### 開火
群烤現在消耗 Roast Charge。人還沒抽？可以先預約。沒能量？叫群友一起補貨。

[去看 Roast Charge →](../gameplay/roast-charge.md)
</div>
<div class="pig-card" markdown>
<span class="pig-card__icon">📰</span>

### 看今天誰最慘
晚一點用 `/豬圈日報` 看看誰是燒烤狂人、最慘食材、逃脫大師或反噬之王。

[翻開日報 →](../gameplay/daily-report.md)
</div>
<div class="pig-card" markdown>
<span class="pig-card__icon">⚙️</span>

### 管理整座豬圈
如果你是管理員，配置、資源、備份、更新與公共豬源都有更完整的管理文件。

[看完整配置 →](../CONFIGURATION.md)
</div>
</div>

## 常用指令先記這幾個

| 指令 | 你會得到什麼 |
| --- | --- |
| `/今日小豬` | 今天屬於你的那一隻 |
| `/我的豬圈` | 永久收藏與 EX Lv. |
| `/昨日小豬` | 昨天真的抽到什麼 |
| `/明日小豬` | 明天的固定預測，不提前解鎖 |
| `/本週小豬` | 七日週報 |
| `/烤群友 @某人` | 把群友送往後廚 |
| `/烤箱補貨` | 發起一次群體補貨 |
| `/添煤` | 參與目前補貨輪次 |
| `/豬圈日報` | 今天整個群發生了什麼 |

完整別名、上下文限制與管理員指令，請直接看 **[指令百科](../COMMANDS.md)**。

!!! warning "舊版升級別直接覆蓋資料夾"
    v3.2.0 起增強版使用獨立插件身份與資料命名空間。你如果是從早期舊版遷移，先看 [運維、身份遷移與恢復](../OPERATIONS.md)，不要拿一個新 ZIP 對著舊資料夾直接梭哈。
