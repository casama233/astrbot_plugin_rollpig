# ⚡ 30 秒開始養豬

如果群裡已經裝好《今日小豬》，普通玩家不用先看配置。先記下面三條就夠了。

<div class="pig-steps pig-steps--player">
<div class="pig-step" markdown>
<span class="pig-step__n">1</span>
<div>

### 抽今天的小豬
<span class="pig-command">/今日小豬</span>

今天第一次抽到後結果固定，重複輸入不會重抽。
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">2</span>
<div>

### 看自己的收藏
<span class="pig-command">/我的豬圈</span>

查看已解鎖的小豬、返場次數和 EX 等級。
</div>
</div>

<div class="pig-step" markdown>
<span class="pig-step__n">3</span>
<div>

### 看目前能玩什麼
<span class="pig-command">/豬豬幫助</span>

幫助卡會依管理員實際開啟的功能顯示可用玩法，不用背全部指令。
</div>
</div>
</div>

## 想搞事時再記這幾條 {.pig-section-title}

| 想做什麼 | 指令 |
| --- | --- |
| 烤某位群友 | `/烤群友 @某人` |
| 發起群體補貨 | `/烤箱補貨` |
| 支持補貨或預約 | `/添柴` / `/添柴 @某人` |
| 看今天群裡發生了什麼 | `/豬圈日報` |

`/添柴` 會按當前情況自動判斷是補貨還是預約；需要指定某張預約時，用 `/添柴 @目標`。
