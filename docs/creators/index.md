# 🎨 親手捏一隻專屬小豬：腦洞大開就把豬交出來

想設計一隻專屬小豬，**你完全不用自己架設插件、不用準備伺服器，更不用學怎麼手寫 manifest。**

對一般群友而言，最無痛的參與方式其實就一句話：

<div class="pig-highlight" markdown>

### 💬 群友專屬極速通道

直接在群裡 **@ 管理員**，把你的小豬點子和素材丟給他。

建議一次備齊以下內容：

- 🐷 小豬大名
- 📝 一句話人設短評
- 🧠 完整靈魂文案／你想玩什麼梗
- 🖼️ 圖片素材或畫面構想
- ⭐ 有的話，也可附上 EX Lv.1–5 的進階差分點子

管理員能直接透過現成的 RollPig 管理後台幫你建檔、測試與微調，品質夠讚的話還能代你投稿至公共豬源。

**你負責大開腦洞，管理員負責把豬塞進系統裡。**

</div>

### A. 普通群友／創作者

**強烈推薦。** 零門檻，不用裝任何軟體。

把你的素材當成「投稿草稿」直接交給管理員即可。後續全由管理員一手包辦：

1. 編配一個合規的專屬 ID；
2. 把圖片轉檔成 RollPig 支援的標準規格；
3. 在自家群組實機測試卡片顯示效果；
4. 陪你一起打磨、潤飾文案；
5. 決定讓牠當本群限定豬，還是送交公共豬源接受人工審核。

如果你只想專心畫圖、寫梗、搞角色設計，**做到這一步就圓滿了。**

### B. 管理員／進階創作者

唯有當你本身就是 RollPig 實例管理員，或打算長期量產小豬時，才需要親自操作管理面板：

- 自行新增或覆寫小豬資料；
- 從 PigHub 挑選現成圖片進行二創加工；
- 實測 EX 差分效果；
- 管理本地覆寫規則與 tombstone 標記；
- 發起公共豬源投稿申請；
- 維護私人的豬隻資源庫。

**不是每個創作者都需要變成運維。**

## 一隻基礎小豬需要準備哪些料？

若由管理員代勞，最核心的是這三項：

```text
名稱：咖啡豬
短描述：今天先不要跟我講話
完整文案：凌晨三點還醒著不是因為自律，是因為你和咖啡建立了錯誤的合作關係。
```

若你自己進管理面板製作，資料庫底層還會多出一個 `id`：

```json
{
  "id": "coffee-pig",
  "name": "咖啡豬",
  "description": "今天先不要跟我講話",
  "analysis": "凌晨三點還醒著不是因為自律，是因為你和咖啡建立了錯誤的合作關係。"
}
```

### `id`

這是系統用來辨識小豬的唯一代碼。**一般投稿者不用傷腦筋，交給管理員代填就好。**

若要親自填寫，請遵守以下規則：

- 僅限使用小寫英文字母、數字、`-` 與 `_`
- 長度 1–64
- 不可與公共豬源既有的 ID 撞名

好的 ID 像：

```text
coffee-pig
sleepy_pig
pig-404
```

### `name`

抽卡時直接秀給玩家看的名字。中文也行、夠騷更好，重點是讓人一眼看懂自己今天抽到了什麼奇葩。

### `description`

簡短介紹。適合塞一句能讓人秒懂牠性格或當下狀態的評語。

### `analysis`

完整文案。這才是整張 RollPig 卡片的靈魂所在。

<div class="pig-highlight" markdown>

**黃金文案公式：**

先讓玩家心頭一驚「靠，這不就是我嗎」，接著再狠狠補上一刀。

例如：

> 「你今天執行力爆表。主要體現在同時開了五個待辦事項、進度條全掛零，並成功把焦慮從早上一路搬運到深夜。」

千萬別寫成生硬的百科條目；請記住，這是一張每天都會被群友瘋狂截圖轉發的梗圖卡。

</div>

## 圖片該怎麼提供？

### 如果你是一般群友

直接把圖檔傳給管理員就搞定了。

手邊還沒成品圖也無妨，用文字描述畫面概念也行，例如：

> 「想捏一隻雙手緊抱咖啡杯、眼神已經徹底失去靈魂的社畜豬。」

後續再由你和管理員討論要找現成素材、委託重繪還是後製加工。

### 你是管理員／進階創作者

透過管理面板存檔後，系統會自動將本地上傳的圖片統一轉為 **512×512 PNG** 格式。

你可以：

- 直接上傳你擁有合法使用權的圖片；
- 在面板內直接從 PigHub 挑選圖庫素材，再填上名字、短評與靈魂文案；
- 先把原圖載下來修好，再重新傳上去。

!!! warning "有圖不代表有授權"
    不管是群友投稿的圖、PigHub 挑的圖，還是網路上找的素材，只要打算公開投稿或再發布，都得確認你擁有圖片和文案的使用權。能下載不代表沒版權。

## 想幫同一隻小豬解鎖 EX 進階形態？

等基礎小豬搞定後，就能接著做 **EX Lv.1–5 差分**。

普通創作者一樣可以直接把差分想法交給管理員，例如：

```text
EX Lv.1：咖啡杯變大
EX Lv.2：桌上多一罐能量飲料
EX Lv.3：描述開始承認昨晚沒睡
EX Lv.4：整張圖開始有「快不行了」的感覺
EX Lv.5：文案正式宣布與咖啡締結終身合作協議
```

在設定上，每個等級都能自由選擇覆寫：

- 圖片
- `description`
- `analysis`

沒填寫的欄位，會自動沿用前一個等級的設定。

EX 差分**不能改動 ID、名字或玩法機制**，它代表的是同一隻豬被重複抽到後的階段性成長，而不是到了 Lv.4 突然基因突變成另一種生物。

具體格式規範請參考 [EX 差分規則](../EX-VARIANTS.md)。

## 📮 如何把小豬投進公共豬池？

主要有兩條路可以走。

### 懶人包：請群管理員代勞投稿

要是你手邊沒有自己架設的 RollPig 實例：

1. 直接在群組裡 @ 管理員；
2. 把小豬名稱、簡介、完整設定文案跟圖片打包交給他；
3. 讓管理員先在本地後台新增並預覽效果；
4. 等你看過確認沒問題；
5. 再請管理員透過管理面板送出公共投稿。

換句話說，**想投稿到公共豬源，並不代表你得自己架設插件。**

### 進階版：親自從管理面板送出投稿

如果你本身就是管理員，可以直接在「本地新增與覆蓋」頁面發起投稿。

## 投稿時會上傳哪些資料？

會提交：

- 小豬 ID
- 名稱
- 描述
- 完整的角色文案
- 符合規格的標準化圖檔

系統**絕對不會**上傳：

- 群友的個人資料
- 群組 ID
- 群組內的聊天紀錄
- SQLite
- JSON 備份
- 你的插件設定檔

## 為什麼顯示投稿成功了，大家卻還抽不到？

因為公共豬源採用**人工審核制**。

送出成功並不等於已經上架。

得等維護者核准並發布新的資源版本後，其他群組的實例在下次同步時才會更新到。

## 哪些情況會導致投稿被退件？

常見的退件原因有：

- 公共豬池裡已經有相同的 ID
- 審核隊列中已經卡著同一個 ID
- 圖片與現有素材重複
- 必填欄位有缺漏
- 圖片規格不符規定
- 檔案容量超過投稿上限
- 短時間內投稿太頻繁，觸發了頻率限制

如果是拜託管理員代投的群友，上面這些技術細節通常管理員會直接幫你搞定。

## 本地新增、覆蓋跟刪除分別是什麼意思？

這一節主要給管理員／進階創作者。

因此正常的資料同步**不會覆蓋或吃掉你在本地的創作**。

## 我想自己維護一套私人豬源

走到這一步，才真正需要接觸 manifest 設定檔。

最精簡的 v1 版 manifest 至少要包含：

- `resource_version`
- `pig_json.path / size / sha256`
- 每張圖片對應的 `filename / path / size / sha256`
- HTTPS 託管

完整的通訊協定、容量限制、原子切換與版本回退說明請看：

- [資源管理手冊](../RESOURCE-MANAGEMENT.md)
- [資源相容性](../RESOURCE-SOURCE-COMPATIBILITY.md)
- [豬源維護](../RESOURCE-SOURCE-MAINTENANCE.md)
