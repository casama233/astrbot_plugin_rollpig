# 🎨 做一隻自己的小豬：有怪點子就先把豬交出來

想做一隻自己的小豬，**你不需要先部署插件、不需要有伺服器，也不需要學會手搓 manifest。**

對普通群友來說，最簡單的路線其實只有一句：

<div class="pig-highlight" markdown>

### 💬 群友最快路線

在群裡 **@ 管理員**，把你的小豬素材交給他。

最好一次附上：

- 🐷 小豬名稱
- 📝 一句短描述
- 🧠 完整文案／你想表達的梗
- 🖼️ 圖片或圖片想法
- ⭐ 如果有，EX Lv.1–5 的差分想法

管理員可以直接用已經部署好的 RollPig 管理面板幫你新增、試跑、修改，合適的話再代你投稿公共豬源。

**你負責想豬，管理員負責把豬塞進機器。**

</div>

## 兩條創作路線

### A. 普通群友／創作者

**推薦。** 不需要安裝任何東西。

你可以把素材當成「投稿草稿」直接交給管理員。管理員收到後，再負責：

1. 補一個合法 ID；
2. 把圖片整理成 RollPig 使用的格式；
3. 在本群實例測試卡片效果；
4. 和你一起修文案；
5. 決定只留在本群，還是送公共豬源人工審核。

如果你只想畫圖、寫梗、做角色設計，**到這裡就夠了。**

### B. 管理員／進階創作者

如果你本來就管理一個 RollPig 實例，或打算長期製作大量小豬，才需要進管理面板：

- 自己新增／覆蓋小豬；
- 從 PigHub 選圖再加工；
- 測試 EX 差分；
- 管理本地覆蓋與 tombstone；
- 發起公共豬源投稿；
- 維護私人資源源。

**不是每個創作者都需要變成運維。**

## 一隻基礎小豬最好準備什麼？

如果你是直接交給管理員，最重要的是下面三樣：

```text
名稱：咖啡豬
短描述：今天先不要跟我講話
完整文案：凌晨三點還醒著不是因為自律，是因為你和咖啡建立了錯誤的合作關係。
```

如果你自己在管理面板製作，資料層還會有一個 `id`：

```json
{
  "id": "coffee-pig",
  "name": "咖啡豬",
  "description": "今天先不要跟我講話",
  "analysis": "凌晨三點還醒著不是因為自律，是因為你和咖啡建立了錯誤的合作關係。"
}
```

### `id`

這是機器真正認豬的名字。**普通投稿者不一定要自己想，管理員可以代為整理。**

如果你要自己填：

- 只允許小寫英文字母、數字、`-`、`_`
- 長度 1–64
- 公共源已存在的 ID 不能再拿來當另一隻新豬

好的 ID 像：

```text
coffee-pig
sleepy_pig
pig-404
```

### `name`

玩家真正看到的名稱。可以中文，可以騷，但最好讓人看完知道自己今天到底抽到了什麼。

### `description`

短描述。適合放一句快速能讀完的性格／狀態。

### `analysis`

完整文案。這裡才是 RollPig 的靈魂區。

<div class="pig-highlight" markdown>

**推薦文案結構：**

先讓玩家「哦，這是在說我」，再補一刀。

例如：

> 「你今天很有行動力。主要體現在打開五個任務、完成零個，以及熟練地把焦慮從上午搬到晚上。」

不要寫成冷冰冰的資料庫描述；它是一張每天會被群友截圖的卡。

</div>

## 圖片怎麼交？

### 你是普通群友

直接把圖片發給管理員就行。

如果還沒有成品圖，也可以只描述想法，例如：

> 「想做一隻抱著咖啡、眼神已經死掉的豬。」

之後由你和管理員決定要不要找素材、重畫或加工。

### 你是管理員／進階創作者

管理面板保存後會把本地上傳圖片標準化成 **512×512 PNG**。

你可以：

- 直接上傳自己有權使用的圖片；
- 從 PigHub 在面板裡挑圖，再補名稱、描述和文案；
- 先下載原圖重修，再重新上傳。

!!! warning "有圖不代表有授權"
    不論是群友交圖、PigHub 選圖還是網路素材，要公開投稿或再發布時，都應確保你有權使用對應圖片與文案。技術上能下載，不等於版權上自動自由使用。

## 想讓同一隻豬長出 EX 變體？

基礎豬做好之後，可以再設計 **EX Lv.1–5 差分**。

普通創作者一樣可以直接把差分想法交給管理員，例如：

```text
EX Lv.1：咖啡杯變大
EX Lv.2：桌上多一罐能量飲料
EX Lv.3：描述開始承認昨晚沒睡
EX Lv.4：整張圖開始有「快不行了」的感覺
EX Lv.5：文案正式宣布與咖啡締結終身合作協議
```

技術上每一級可以選擇覆蓋：

- 圖片
- `description`
- `analysis`

沒有配置的欄位會向較低等級繼承。

EX 差分**不能改 ID、名稱或玩法規則**，它是同一隻豬被反覆抽到後的成長，不是 Lv.4 突然換成另一個物種。

詳細格式看 [EX 差分規則](../EX-VARIANTS.md)。

## 📮 怎麼投稿公共豬源？

有兩種方式。

### 最簡單：請群管理員代投

如果你沒有自己的 RollPig 實例：

1. 在群裡 @ 管理員；
2. 把名稱、描述、完整文案和圖片交給他；
3. 管理員先在本地新增並預覽；
4. 你確認效果沒問題；
5. 由管理員從管理面板發起公共投稿。

所以**想投稿公共源 ≠ 你必須自己部署插件。**

### 進階：自己從管理面板投稿

如果你自己就是管理員，可以從「本地新增與覆蓋」發起投稿。

## 投稿會傳什麼？

會提交：

- 小豬 ID
- 名稱
- 描述
- 完整文案
- 標準化圖片

**不會**提交：

- 群友資料
- 群組 ID
- 聊天內容
- SQLite
- JSON 備份
- 插件配置

## 為什麼投稿成功了，別人還看不到？

因為公共源是**人工審核**。

成功提交 ≠ 成功發佈。

維護者批准並生成新資源版本後，其他實例還要等下一次同步才會看到。

## 什麼情況可能被拒絕？

常見包括：

- 公共源已存在同 ID
- 待審核隊列已經有同 ID
- 重複圖片
- 欄位不完整
- 圖片不符合限制
- 超過投稿大小限制
- 來源短時間投稿過多，觸發限速

如果是群友把稿件交給管理員代投，這些技術性問題通常也由管理員協助處理。

## 本地新增、覆蓋、刪除是什麼？

這一節主要給管理員／進階創作者。

<div class="pig-layer-stack">
  <div class="pig-layer pig-layer--top"><strong>刪除屏蔽層</strong><span>你明確不要的 ID，優先級最高</span></div>
  <div class="pig-layer pig-layer--mid"><strong>本地覆蓋層</strong><span>新增、改名、改文案、自訂圖片</span></div>
  <div class="pig-layer pig-layer--base"><strong>基礎層</strong><span>AstrBot 公共源／私人源；失敗時回退內置資源</span></div>
</div>

所以正常同步**不應該吃掉你的本地創作**。

## 我想自己維護私人豬源

到這裡才真的需要進入 manifest 世界。

最小 v1 manifest 需要：

- `resource_version`
- `pig_json.path / size / sha256`
- 每張圖片的 `filename / path / size / sha256`
- HTTPS 託管

完整協議、大小上限、原子切換與回退方式：

- [資源管理手冊](../RESOURCE-MANAGEMENT.md)
- [資源相容性](../RESOURCE-SOURCE-COMPATIBILITY.md)
