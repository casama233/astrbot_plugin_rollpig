# Discord 輸入 `/` 沒有選單

**文字指令能回覆，不代表選單已註冊成功。** 選單需要 AstrBot 把指令清單送到 Discord，並由 Discord 接受。

## 先確認是哪一種問題

| 看到的情況 | 接著做什麼 |
| --- | --- |
| 完全沒有這個機器人的指令 | 管理員檢查下方的註冊開關與同步紀錄 |
| 有其他指令，唯獨沒有小豬 | 確認小豬插件已啟用，再重新連線 Discord 適配器以同步清單 |
| 選單能選，但沒有回覆 | 改查插件回覆、權限與網路錯誤；這是另一段流程 |
| 只有某個人或頻道看不到 | 檢查 Discord 的「使用應用程式指令」權限與伺服器的整合設定 |

小豬在原生選單使用簡體主指令，例如 `今日小猪`、`我的猪圈`。繁體等別名可直接在聊天裡使用，未必會逐個出現在選單。

## 管理員：先看註冊紀錄

1. 在 AstrBot 的 Discord 設定確認 `discord_command_register` 已開啟。
2. 檢查 Discord 連線後的日誌。`Ready to sync` 只表示清單準備好了；要看到 `Command synchronization completed` 才表示同步請求成功。
3. 如果有錯誤，按下面處理。修復後只重連 Discord 適配器，再確認結果。

| 日誌訊息 | 原因與處理 |
| --- | --- |
| `50035`，`Application command names must be unique` | 同名指令重複送出，Discord 拒絕整批。應修正 AstrBot 適配器的註冊去重，保留處理順序中優先的同名項；不用刪除小豬資料或改掉玩家指令。 |
| `30034` | Discord 的每日建立指令配額已用完。停止反覆重註冊，等配額恢復。 |
| 權限或授權錯誤 | 檢查機器人的安裝範圍是否包含應用程式指令，以及所在伺服器的整合權限。 |
| 網路或逾時錯誤 | 檢查 Discord 代理與連線；修好連線後再同步。 |

!!! note "文字指令可先使用"
    選單修復前，可直接發送 `/今日小豬`。是否需要先 @ 機器人，取決於 AstrBot 的喚醒設定。

原生選單屬於 AstrBot 的 Discord 適配器。小豬插件負責提供指令和處理回覆；把插件重裝多次，不能修好適配器送出的重名清單。
